# Base de Datos – Modelado y Gestión de Información

Material teórico y práctico desarrollado en la materia **Base de Datos**  
Carrera: Ingeniería Informática.

---

## Contexto

En esta asignatura se estudiaron los fundamentos del diseño, implementación y administración de bases de datos relacionales.

Se trabajó en el modelado conceptual y lógico de sistemas de información, así como en la creación y manipulación de estructuras de datos mediante lenguaje SQL.

---

## 🎯 Objetivos

- Comprender el modelo relacional  
- Diseñar esquemas de bases de datos  
- Implementar tablas, relaciones y restricciones  
- Realizar consultas mediante lenguaje SQL  
- Garantizar la integridad y consistencia de los datos  
- Analizar la eficiencia en el acceso a la información  

---

## Contenidos Trabajados

- Modelado entidad–relación  
- Normalización  
- Claves primarias y foráneas  
- Restricciones de integridad  
- Lenguaje DDL y DML  
- Consultas SELECT, JOIN, GROUP BY  
- Vistas e índices  
- Transacciones y control de concurrencia  

---

## Actividades Prácticas

- Diseño de modelos de datos  
- Transformación de modelos conceptuales a modelos físicos  
- Creación de bases de datos mediante SQL  
- Inserción, actualización y eliminación de datos  
- Desarrollo de consultas complejas  
- Resolución de ejercicios de análisis de información  

---

## Habilidades Desarrolladas

- Diseño lógico de sistemas de información  
- Pensamiento estructurado orientado a datos  
- Programación en SQL  
- Optimización básica de consultas  
- Documentación de estructuras de datos
